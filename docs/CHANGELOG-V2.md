# 予舍 V2 修改记录

## 页面与入口

删除首页、页脚、英文映射和说明中的旧活动参赛标识；保留实际模型服务与正常商品目录。首页突出装修签约专员，补充三方确认、阶段履约和演示标识。

业主竞标表增加选择公司按钮。业主项目、公司订单、平台订单接入同一个合同履约工作台。公司投标服务费预估改为合同服务费口径；旧利润分成只读显示，现有会员服务独立保留。

## 合同与履约

新增版本化合同数据与接口，包含主体资料、报价设计快照、附件、分期、三方确认与演示签署。公司先确认，业主可议价；变更后重新确认，部分签署留存，全签正文只读。

增加公司私有签约资料、公章授权、签名上传与手写、下载打印；阶段证据、业主验收、驳回整改、模拟入金和分期结算、服务费、退款与争议记录。新流程不在签署时自动产生旧整单分成。已有合同或资金历史受到删除保护。

新增模型只读复核适配，缺配置时明确未调用模型；规则草案独立可用。所有操作按服务端角色与订单归属验证，并使用版本校验、幂等键和真实数据库事务。

## 交付边界

正式电子签署、实名与授权认证、真实资金托管/出款/退款服务商及复杂补充协议尚未接入。现有模拟签署和资金状态不会被描述成这些正式能力。已签正文修改安全拒绝，后续另行办理补充协议。

本次修改仅在本地源码完成，未部署到远程网站。升级保留原环境配置和数据，并先备份；具体操作见 V2使用与部署说明.md。
