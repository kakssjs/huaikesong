# 予舍团队定位调整说明

予舍的产品定位为 AI 装修智能体团队，覆盖任务调度、户型识别、方案设计与同源3D、报价工期、交付质检、施工方匹配，并接续签约和履约。

本次修正首页主标题、搜索描述、中英文展示与团队分工；增加各岗位输入和交付说明，并补回首页流程中的质检。3D呈现按设计数据的工具能力说明，不把每项工具虚构成独立运行的智能体。

小调、小测、小设、小算、小检、小桥沿用现有角色配置。项目页已有真实fromAgent/toAgent、任务状态、异常和人工待办记录，本次不修改执行逻辑、不写入示例完成记录。

签约专员是团队业务链中的后续岗位。V2新增的三方合同、签章、阶段验收和模拟结算完整保留，规则草案与可选模型复核的边界不变。

此前V2文档中“聚焦签约专员”的建议，只能作为一次参赛演示选题，不能作为项目全部AI能力的定义。参赛可介绍完整团队，再选择有真实证据的关键岗位或核心任务深入展示，岗位选择应以实际执行和交付质量为依据。

本版仅修正本地项目的定位与展示，未部署远程网站，未声称重新验证外部模型质量。源码包在原有升级说明外附本说明。
