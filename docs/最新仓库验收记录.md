## 复现方式

先 `npm ci`、`npm run build`，再设置 `PLAYWRIGHT_CORE_PATH` 为 playwright-core 安装目录（本次使用1.56.1）、`CHROME_PATH` 为现有 Chrome 路径，执行：

```text
node scripts/chat-http-smoke.cjs --isolated-demo --browser
node scripts/browser-acceptance.cjs --isolated-demo
node scripts/chain-acceptance.cjs --isolated-demo
```

各脚本自建隔离测试目录与服务；合同模式使用 `CONTRACT_MODE=demo`。不要改为生产数据目录。
